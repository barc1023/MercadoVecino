# Manual de usuario

## Crear una cuenta

1. Abre **Regístrate**.
2. Escribe nombre, correo y contraseña de al menos seis caracteres.
3. Pulsa **Crear cuenta**. La aplicación inicia sesión y abre el inicio.

## Iniciar y cerrar sesión

1. En **Inicia sesión**, escribe el correo y la contraseña.
2. Usa el menú lateral para recorrer las secciones habilitadas por tu rol.
3. Selecciona **Cerrar sesión** al terminar. La aplicación elimina la caché de sesión del teléfono.

## Hacer y seguir un pedido

1. Abre **Mis pedidos** y pulsa **Nuevo pedido**.
2. Indica producto, cantidad, dirección y notas opcionales.
3. Pulsa **Confirmar pedido**.
4. Abre el pedido en la lista para ver su detalle y estado.

## Cancelar un pedido

Solo se pueden cancelar pedidos pendientes. En su detalle pulsa **Cancelar pedido** y confirma la acción. El pedido no se borra: queda marcado como cancelado en el historial.

## Comerciante

El comerciante abre **Gestionar pedidos** desde el menú. Cada pedido permite avanzar al siguiente estado disponible. Los cambios se muestran en tiempo real al cliente.
